# Python Fundamentals

This repository holds the course notes and practice for Python Fundamentals class. Each lesson has written notes (Markdown and a matching `.py` file) plus lab exercises that apply the same topics.

## What's inside

| Folder                                  | Contents                                   |
| --------------------------------------- | ------------------------------------------ |
| `lesson1`–`lesson9`                     | Class notes and lab exercises              |
| `challenges`                            | Extra lab challenges                       |
| `checkpoint-lessons1–6`                 | Mid-course checkpoint covering lessons 1–6 |
| `the_final_project_python_fundamentals` | Final project                              |

## What we worked with

Throughout Python Fundamentals, we have built a toolbox for solving programming problems with Python.
We explored the following concepts:

- variables, data types and operators
- strings and type conversion
- lists, tuples, sets and dictionaries
- conditions and loops
- functions, parameters and return values
- default and keyword arguments
- type hints and docstrings
- scope
- `*args` and `**kwargs`
- unpacking
- list, dictionary and set comprehensions
- `enumerate()` and `zip()`
- lambda functions
- `map()` and `filter()`
- classes and objects
- attributes, methods and object state
- instance and class attributes
- collections of objects
- objects containing other objects
- inheritance and `super()`
- method overriding
- polymorphism
- duck typing
- `isinstance()`
- `str()`
- IS-A and HAS-A relationships
- composition
- validation

## Run an exercise

Most of the examples and exercises are commented out. To see a piece of code in action, uncomment that section and comment out the others, then run the file. Only one section should be active at a time, so later examples do not run over earlier ones.

Exercises are plain Python scripts. From the repository root:

```bash
python lesson1/lab1/lesson1_exercises.py
```

Swap in any other lesson file the same way. No extra packages are required.
